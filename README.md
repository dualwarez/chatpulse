# 💬 ChatPulse — rooms that feel alive

Real-time chat rooms built on the **Nexconn Chat SDK** (Web) for the Nexconn Build Challenge 2026.

- 🔐 Server-side token issuing (Nexconn Chat Server API, SHA1 signature)
- 🌍 4 live open channels with history + real-time delivery
- 🎨 Dark, polished UI — zero logins, pick a name and go

## Run
```
npm install
node server/server.mjs   # token API + static host on :8787
npx vite --port 5180     # dev client
```
